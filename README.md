# Jagruthi — Portfolio (GitHub Pages ready)

Open `index.html` in Chrome or publish these files at the root of your GitHub Pages `Portfolio` repository. `assets/` must sit next to `index.html`.

## What is included
- Homepage with portrait, Story / Journey, Skills, Projects, Off the Clock, contact links, interactive Game Mode.
- Real Trekker, Nerf, ChronoMind, and ASTRA imagery, along with your own sunset photographs.
- Roadster-inspired **concept illustration** in the featured section and project gallery, **not a photograph of the actual student build or a Tesla promotional photo**. The prototype remains in development.
- `assets/original_ambient.ogg`: 24-second **original** ambient loop, with a click-to-play / pause music control. No Tame Impala audio. Your browser will not autoplay sound until you click.
- Off the Clock does not include Cooking or Languages, as requested.

## To publish
Copy all files and the `assets` directory into your existing `jagruthig2020-ship-it/Portfolio` repository root and push to `main`. GitHub Pages should serve `index.html`.
