# Jagruthi Guttula

This is my portfolio: the things I'm building, the experiences that got me here, and a little about me outside projects.

I'm from Hyderabad, studying computer science, and usually working on something late at night. Sometimes it's code. Sometimes it's a sensor that still won't give me the reading I expected.

I wanted the site to feel like something you could explore, so there's a little Spider-Man influence, web transitions, and a game called The Red Thread.

Each project has its own notes: why I started, what went into it, and where it stands. Some are solo builds, some are with my teammates, and some are still in progress. I'll add demo videos when they're ready.

## Run locally

Windows: open START_WINDOWS.bat.

Mac: run python3 serve_portfolio.py.

No install or build step. Keep the assets and project pages together.
