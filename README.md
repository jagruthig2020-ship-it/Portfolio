# Jagruthi Guttula — Portfolio

I wasn't particularly interested in computer science when I first started. That changed gradually, somewhere between getting my first programs to work, experimenting with hardware, and realizing how many different things I could make.

This is my personal corner of the internet. It's part portfolio, part collection of experiments, and a little bit of an excuse to try interesting web interactions. I wanted the projects to feel like things you can explore, rather than a list of screenshots.

**[Visit the portfolio](https://jagruthig2020-ship-it.github.io/Portfolio/)** · [GitHub](https://github.com/jagruthig2020-ship-it) · [LinkedIn](https://www.linkedin.com/in/jagruthi-guttula-a20811277) · [Résumé](Jagruthi_Guttula_Resume_2026-11-02.pdf)

## What's here

The site opens with a short introduction and moves through an animated web of experiences: school, DexSchool and Dexterity Global, college, hackathons, and the things I've worked on since. There's also a small playable side quest, *The Red Thread*, and an Off the Clock section with some of my own sunset photos.

The project gallery includes **Trekker, Nerf Controller, ChronoMind AI, Paradox, Circuit Studio, RaceOS, KIKO, TREE, ASTRA, and MILO**. My current major focus is an independent **Tesla Roadster-inspired miniature demo**. The Roadster project is in development; the image is concept artwork, not a photograph of a completed build or an official Tesla image. MILO is another in-development idea: a teddy-bear-inspired elderly-care companion. Its gallery art is a concept illustration, not a photograph of a built robot.

Not everything here is finished. Some projects are working prototypes, some are experiments I keep returning to, and a few are still being built. I've tried to label them that way rather than making every idea look like a finished product.

## Running it locally

Clone the repository and open `index.html` in Chrome or another modern browser. The website is static: no API keys, database, or build command needed. Keep the `assets` folder and the résumé PDF beside `index.html`.

```bash
git clone https://github.com/jagruthig2020-ship-it/Portfolio.git
cd Portfolio
```

You can also use a local server if you prefer:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

The background music player uses `assets/portfolio_instrumental_selected_2026-11-02.mp3` (a user-supplied instrumental recording). Visitors can click **PLAY MUSIC** in the header or the small floating music toggle to start or pause it. There is no embedded video. Browsers generally require a click before playing audio. **MY TRACK** lets visitors choose a local audio file they are authorized to use, without uploading it. The contact form prepares an email draft; it does not silently send or store messages.

## A note on the visuals

The photos of my work, events, and sunsets are from my own collection. Some project cards use illustrative artwork where I don't have suitable screenshots yet. The Roadster illustration is just a visual reference for a student concept, not a claim that I've finished the car or that Tesla is involved.
