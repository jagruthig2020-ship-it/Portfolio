01 / THE REASON

Why we built it.

We wanted someone to be able to ask for help with a physical button. So we started putting the button, location sensing, and movement sensing into a wearable. TREKKER is our attempt to make that first action easier when reaching for a phone isn’t convenient.

02 / THE BUILD

How it works.

An ESP32 connects the sensors and a physical SOS button. GNSS supplies location; the motion sensor adds activity information. The intended flow is to pass the useful details to a phone or dashboard when help is needed.

  1. 01

    Press SOS

    A physical action on the wearable.

  2. 02

    Read the sensors

    Location and movement information.

  3. 03

    Pass it on

    Phone delivery is still being tested.

03 / RIGHT NOW

Where it stands.

The hardware is a prototype. Reliable phone delivery, continuous sensing, and outdoor operation still need more testing.
