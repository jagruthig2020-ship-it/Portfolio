01 / THE REASON

Why we built it.

We had a Nerf blaster and wanted to see what we could make it respond to. We added motion sensing, buttons, lights, and a buzzer. A lot of the work came down to small adjustments: which movement counts, and when should the feedback happen?

02 / THE BUILD

How it works.

An ESP32 reads an MPU6050 and button inputs. The firmware uses those signals to drive lights and buzzer feedback. The work is in making physical readings stable enough to respond consistently.

03 / RIGHT NOW

Where it stands.

The controller was built and tested as a hardware experiment. Sensor thresholds and the physical setup can still be refined.
