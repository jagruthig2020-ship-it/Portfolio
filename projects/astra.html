01 / THE REASON

Why we built it.

We wanted to see a system notice that something had gone wrong, shut down a payload, and try to recover. So we built a spacecraft-inspired testbed with a main ESP32 and a second board watching it. The interesting part is what happens after the fault.

02 / THE BUILD

How it works.

A main ESP32 and a supervisor exchange heartbeat and sensor information. The recovery logic moves through detection, payload shutdown, and a recovery attempt, with telemetry making the state visible.

  1. 01

    Watch

    A supervisor checks the main board.

  2. 02

    Detect

    Heartbeat or sensor data signals a fault.

  3. 03

    Recover

    Test the shutdown and recovery sequence.

03 / RIGHT NOW

Where it stands.

The hardware and recovery logic are experimental and still need debugging. Reliable fault handling and repeatable recovery tests remain the important unfinished work.
